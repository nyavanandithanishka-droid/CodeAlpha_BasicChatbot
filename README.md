# Basic Chatbot - Python

A simple rule-based chatbot built using Python. The chatbot responds to predefined user inputs such as greetings, questions, and exit commands. This project was developed as part of the CodeAlpha Python Programming Internship.

## Features

* Interactive text-based conversation
* Predefined responses for common inputs
* Continuous chat until user exits
* Beginner-friendly implementation
* Simple console-based interface

## Concepts Used

* Python
* Functions
* if-elif-else statements
* Loops
* User input handling
* String operations

## Objective

To create a simple chatbot that can interact with users through predefined responses and demonstrate the fundamentals of conversational programming.
